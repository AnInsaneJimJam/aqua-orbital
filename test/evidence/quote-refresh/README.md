# Quote and review timing repair

September 9, 2026. The old review deadline was `min(indexedAt + 10s, quoteExpiry)`. The UI refreshed only every ten seconds, disabled Review during background fetching and stopped refreshing after transport errors. Three [live Arc observations](live-api.json) through the updated bounded retry helper returned HTTP 200 / `QUOTE_OBSERVED`; their old review clocks had only about 6.4–7.2 seconds remaining before any wallet preflight. An earlier direct probe returned `QUOTE_INDEXER_STALE`.

API identity, ten-second index admission age, twenty-second quote lifetime and onchain settlement bounds remain enforced. An admitted fresh draft proceeds through independent live preflight. The resulting immutable review lasts up to sixty seconds from preflight completion, capped ten seconds before its transaction/invoice deadline. Submit rechecks live state, canonical pins, exact simulation, balance/allowance, account and gas budget; old API timestamps are never rewritten. Live block age is checked through wallet handoff. Changed minimum feasibility, strategy version, invoice terms or gas budget still require another review. A slow signature can still outlast the onchain transaction deadline.

Swap-funded payment calldata is reconstructed locally with a three-minute deadline capped by invoice expiry after validating the API's original plan; spend, route, recipient and minimum stay fixed. Review details remain visible during the wallet prompt. Public quotes refresh about every five seconds, recover from transient expiry/index failures, and use a fifteen-second background failure backoff. Reviews pause repricing. A background read cannot sign, and expired estimates remain hidden. Invoice history previously toggled `payable` off whenever polling started; it now preserves payment eligibility during a poll and normal canonical index advancement. Actual terminal/unavailable observations still invalidate payment eligibility.
